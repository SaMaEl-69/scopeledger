## Shared ownership

`Workspace` remains the source of truth. Projects reference reusable clients and preserve current/original baselines. Changes reference projects. Approvals/revisions bind to exact change revisions; reconciliations keep before/after baselines. Issued documents freeze client-facing values with stable project/change/revision links. Payments reference issued documents. Calendar source events derive from project/document dates; manual reminders have separate stable identities. Comparisons, scenarios, assumptions and activity share the backup graph.

Archive/trash retain financial history, with hidden-history attention disclosed. Duplication remaps selected editable records instead of copying invoices or asserting approvals. Restore replaces the graph deliberately and retains IDs; repeated restore creates no duplicates. Currency labels do not convert amounts.

Browser records cannot assert server entitlement. Allocation and quotas live in the durable server database; keys/sessions never enter workspace backups. Dev/preview/static routes block private files and configured database aliases, post-verification authorization rechecks the live session, and export quotas reserve atomically. Devices have independent data. Live purchases remain disabled until real seller configuration and explicit launch authorization.
