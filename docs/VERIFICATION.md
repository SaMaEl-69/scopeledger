## Brief and invoice refinement

The shared preview/export renderer now uses a minimal white/navy design with a compact reference block, restrained agency accent, clear public fee summary and contrasting invoice/credit total. Ordinary sample briefs and invoices fit one page; long content remains flowable and huge totals stay unbroken in print. Compact supporting brief terms use two columns only when bounded short text fits; longer terms use ordinary document flow. Proposed/agreed fees and credits are labeled according to status. An invoice's frozen Total is distinct from the app's current manual outstanding balance. Opaque source UUIDs stay in the preserved payload; visible client documents use revision information instead.

Documents now exposes the type picker and Prepare invoice at the top, resumes separate temporary drafts, links counted history, sorts accepted ISO instants, resets empty filters, and makes issued/payment history clearer. Editors that do not appear on invoice/credit output are hidden without deleting their draft values. Approval, readiness, unique-reference, immutable-history and payment checks remain intact. A confirmed private-transfer gap was fixed by validating the public allowlist before fetch; failed download setup also releases its blob and permits retry. New regressions cover those failures, positive/credit agreement labels, frozen totals after receipts and the document workbench.

## Reproduction

Run browser processes sequentially:

```sh
npm test
npm run build
npm run test:cross-browser
npm run test:audit
npm run test:local-browser
# Start npm start in another terminal before the following measurements:
npm run test:performance
npm run test:crowded
npm run test:pdf
```

For manual owner testing, generate private local keys once with `npm run keys:local`, then use `npm run dev:local`; never overwrite or expose `.local-private`. Automated local browser journeys use separate temporary servers/keys instead.
