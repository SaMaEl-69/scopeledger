# Using the workspace

The workspace guides each project through seven clear steps, showing the controls needed for the current task. Existing projects, approvals, issued documents and payment history retain their records.

## Find the right place

| Page              | Use it for                                                                                |
| ----------------- | ----------------------------------------------------------------------------------------- |
| Overview          | Next actions, upcoming work and unpaid invoices.                                          |
| Projects          | Choose an existing project or start a new one.                                            |
| Change requests   | Describe a request, estimate its cost, choose a response and review the decision.         |
| Documents         | Prepare briefs, invoices or credit notes; open saved documents and track manual payments. |
| Calendar          | Project deadlines, invoice due dates and manual reminders.                                |
| Clients           | Reusable client information and billing details.                                          |
| Templates         | Reusable scenarios, assumptions and client wording.                                       |
| Settings & backup | Agency details, defaults, device access and backups.                                      |

Overview, Change requests and Templates were previously called Dashboard, Change workspace and Agency playbook/Playbook. The records and financial rules behind these pages are unchanged.

## Everyday actions

Overview and the other workspace pages provide **New project**, **New request**, **Create document** and **Add reminder** below the page heading. In the focused project workflow, **New project** appears at the Project step and **New request** at the Change step. **Show all steps** restores the full editor and its action rail. Desktop shows **Shortcuts** beside these actions; on a phone, keyboard help remains in navigation and Find anything. New request adds a draft to the current active project. Create document opens Documents for the current project and request. Add reminder opens a reminder form with the current context.

**Find anything** at the top opens a searchable list of actions, pages and active projects. Search for a project name, “invoice”, “brief” or “backup”. Selecting **Prepare a client brief** or **Prepare an invoice** opens that editable document purpose directly. Existing edits to the same purpose remain available.

## Follow the next step

The default Change requests view follows this sequence:

**Choose a project → Complete its baseline → Load or describe a change → Review costs → Choose a fee → Review the brief → Export.**

| Step        | What is visible                                                                                             | What Continue does                                                |
| ----------- | ----------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| 1. Project  | Current project chooser and New project                                                                     | Opens the selected project's baseline.                            |
| 2. Baseline | Approved scope, fee, delivery costs and target margin; Review baseline                                      | Opens baseline editing when required, or continues to the change. |
| 3. Change   | Current request chooser, New request, examples, description, deliverables and a plain-language type chooser | Checks the required scope details, then opens costs.              |
| 4. Costs    | Hours needed, hourly cost, extra expenses and explicit scope savings                                        | Checks the delivery estimate, then opens the fee.                 |
| 5. Fee      | Plain-language response choice, proposed fee, a compact cost/margin summary and agreement confirmation      | Checks the response, then prepares the public brief.              |
| 6. Brief    | Brief / Invoice / Credit note switch, full document preview, Edit document details and All documents        | Continues to Export when document requirements are complete.      |
| 7. Export   | Reviewed brief and explicit PDF action                                                                      | Downloads an authorized PDF, or opens activation if needed.       |

**Back** and **Continue** remain visible at the bottom on desktop and phone. The seven numbered buttons let you revisit steps. Jumping to Brief or Export returns to missing baseline, scope, cost or agreement details; entering Export from the editor opens Brief first. If you are not estimating yet, **Keep this request for later** in Costs selects a deferred response and moves to Fee. Unknown estimates remain unchanged. Deferred requests retain their existing no-delivery, no-date, no-fee commitment rules; the focused view hides the unused fee and agreement inputs.

The type chooser uses **Additional work**, **Already in the agreed scope**, **A correction** and **Needs clarification**. The response chooser uses **Charge for the additional work**, **No additional charge**, **Replace some existing work** and **Keep this request for later**. These controls use the existing classifications and response rules. Choosing No additional charge shows zero as the effective fee without overwriting a previously entered proposed fee.

In Fee, the cost and margin summary sits below the proposed fee, followed immediately by agreement confirmation. **Add a client credit** and **Timing and conditions** expose optional details. **View financial breakdown** opens the detailed calculations; save, approval and approved-work inclusion controls remain below it. The brief's values and issuance safeguards remain unchanged.

**Show all steps** restores the complete editor, including planning, history, comparisons and response tools. **Focus on one step** returns to the quieter presentation. These are views of the same draft. Choosing a step never records approval, includes work in the baseline, issues an invoice or starts an export. Those actions retain their explicit controls and safeguards.

In the guided document review, the **Brief / Invoice / Credit note** switch selects the document without leaving the seven-step workflow. Each kind retains its own draft settings. **Edit document details** reveals document settings and the optional snapshot/issue action. Missing document requirements remain visible automatically; invoices still require recorded approval and valid billing details. The selected kind carries through Export and Back. **All documents**, the Documents navigation item or its shortcut opens the normal document hub for saved records and payments.

## Filters without clutter

Overview keeps Project and Currency visible. **More filters** contains Client, Status, date range and sample/archive/trash options. Calendar keeps Project visible, with Event type, Status and reminder trash under More filters. Active advanced filters are counted on the disclosure so a collapsed filter cannot silently explain a missing result. **Reset filters** returns each page to its defaults.

Overview excludes sample work by default. Its date and status filters retain their existing financial meanings; the explanation under More filters describes how they affect totals. Calendar source deadlines remain linked to the original project or issued document. Calendar reminders work while the app is in use; no email or closed-app notification is sent.

## Prepare a document

Documents presents **Prepare brief**, **Prepare invoice** and **Prepare credit note** together. Choose the project/request if needed, then use the highlighted missing details. Each missing item takes you straight to the needed input or source page. **Agency details**, **Client details** and **Scope & approval** provide additional direct routes.

The save/issue action appears before the editable document fields and stays disabled until the required details are valid. Completed checks are grouped separately. The preview updates as you edit. Invoices and credits still require approval for the current revision; credits require the approved negative adjustment and its explanation. Saving a brief preserves a copy without approving the request.

Brief, invoice and credit settings remain independent while the page stays open. Switching purpose or using an explicit preparation action restores its edited draft. Reloading clears temporary settings, including malformed entries kept for correction. **Prepare new document** appears for an edited draft or saved record; replacing edited settings requires the existing reset confirmation. Only a confirmed snapshot preserves the exact document in workspace history and backups.

**Signatures** is beside the preview, including Step 6 of the guided workflow. Open it to enter an issuer or client name, role and date, or use **Import signature** for a PNG/JPEG up to 2 MB. Images are fitted proportionally and transparency is preserved. Replace or remove each image independently. The client area is included by default for a brief and optional on invoices and credit notes; the entire sign-off area can be switched off. Blank fields become signing lines in the PDF. Imported images do not record approval or unlock invoicing.

Signature settings follow each independent document draft. Save a brief snapshot or confirm invoice/credit issue to preserve the image and details in document history and backups. Unissued imports clear on reload, just like the other temporary document settings. Saved documents keep their signatures when current details change; older preserved documents remain valid without acquiring new signature fields.

**Saved documents & payments** opens chronological history. Select a saved invoice or credit to inspect its frozen values, download an authorized PDF, or record a manual payment/settlement. Editing current defaults does not rewrite it. Manual tracking does not process money. Issuance, payment records and void actions retain their explicit checks and confirmations.

## Keyboard quick reference

Mac uses Command (⌘) and Option; Windows/Linux use Ctrl and Alt. The on-screen shortcut help uses the platform's modifier labels.

| Action                                             | Mac                | Windows/Linux        |
| -------------------------------------------------- | ------------------ | -------------------- |
| Find anything                                      | ⌘ + K              | Ctrl + K             |
| Open a new project form                            | Option + Shift + P | Alt + Shift + P      |
| Create a new request in the current active project | ⌘ + Shift + Enter  | Ctrl + Shift + Enter |
| Open Documents                                     | Option + Shift + D | Alt + Shift + D      |
| Add a reminder                                     | Option + Shift + R | Alt + Shift + R      |
| Choose a project                                   | Option + 1         | Alt + 1              |
| Complete its baseline                              | Option + 2         | Alt + 2              |
| Load or describe a change                          | Option + 3         | Alt + 3              |
| Review costs                                       | Option + 4         | Alt + 4              |
| Choose a fee                                       | Option + 5         | Alt + 5              |
| Review the brief                                   | Option + 6         | Alt + 6              |
| Export                                             | Option + 7         | Alt + 7              |
| Show shortcut help                                 | ?                  | ?                    |

Find anything works while typing in a field. Other action and step shortcuts pause in inputs, text areas, selections and editable text. All action shortcuts pause while a dialog or mobile navigation is open, and during recovery. Held/repeated keys and text composition do not repeatedly trigger actions. Command/Ctrl + Shift + Enter is also prevented from submitting a form while its new-request action is paused.

In Find anything, use Up/Down to choose, Enter to open and Escape to close. Use Tab to move between ordinary controls and Enter to use the focused button. Escape closes a dialog through its existing unfinished-entry guard. No shortcut bypasses approval, document issuance, payment, activation, reset or restore requirements.

## Appearance

Use **System**, **Light**, or **Dark** under Appearance in the workspace navigation. System follows your device's current appearance and updates when it changes. Manual choices override the device setting until you choose System again. Home has the same choices beside its navigation actions and in its footer. Selections synchronize between open tabs and survive reloads when browser storage is available. With enlarged workspace text, the three choices stack to keep every label readable.

Demo previews have a repeated watermark across the paper. Activation gives you clean previews and PDF exports. The watermark identifies demo captures; it cannot prevent screenshots.
