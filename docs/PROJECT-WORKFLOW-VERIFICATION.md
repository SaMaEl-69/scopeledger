# Seven-step project workflow verification

Historical acceptance for the seven-step workflow, verified locally on **6 October 2026**. The subsequent plain-language workspace and document redesign is covered by [workspace and document refinement](WORKSPACE-DOCUMENT-REFINEMENT.md). The default project workspace now follows **Choose a project → Complete its baseline → Load or describe a change → Review costs → Choose a fee → Review the brief → Export**. Each stage shows its relevant controls, with a persistent Back/Continue bar, a quiet numbered navigation strip and Alt/Option + 1–7 shortcuts. Show all steps restores the complete editor. [The usage guide](WORKSPACE-USABILITY.md) describes these controls.

The brief opens as a full document preview. Edit brief details exposes the document settings; missing requirements remain visible automatically. All documents returns to invoice, credit and saved-record tools. Export is a deliberate final action using the established server authorization and duplicate-job guard. Moving through the sequence does not quote, approve, reconcile, preserve a document snapshot or issue an invoice.

## Reproduce and limits

Run `npm test`, `npm run build`, `npx playwright test --config playwright.usability.config.ts`, `npm run test:cross-browser`, `npm run test:local-browser`, `npm run test:site` and the affected tests in `playwright.audit.config.ts`. `node scripts/sequence-runtime.mjs` records normal navigation and guided-stage runtime errors. Built checks use port 4173; operational checks use port 5173. Each origin has independent browser records.

Firefox's backend cannot emulate the mobile context used by the touch-entry test; its ordinary narrow-screen and keyboard checks do run. Physical devices, native screen-reader behavior, keyboard layouts and production deployment are not established by these automated checks. The existing Vite main-chunk size advisory remains. Hosting and real checkout are not configured. Real backend tests use local development entitlement, not a live purchase.
